- The Mac app is now signed with a Developer ID and notarized by Apple. Unzip `Scion-osx-arm64-Portable.zip` (Apple silicon) and open `Scion.app`: macOS opens it without a warning, and the Terminal command that earlier Mac versions needed is gone.
- The Mac downloads have new names, `Scion-osx-arm64-Portable.zip` and `Scion-osx-x64-Portable.zip`. If you have an earlier Mac version, download this one once: the earlier ones do not update themselves. From this version on, the Mac app looks for updates in the same releases as the Windows one.
- The Mac app has an icon now.
- The Intel build is signed and notarized the same way. It has not been tried on an Intel Mac yet.
- The Windows app has no functional changes in this release.
